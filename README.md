# 她启 · 产品初版

制作日期：2026-10-13。

这是可以操作的Web初版，主要面向曾有职业经历、因生育或照护暂停工作的女性。首页以重返原职业、探索转型或灵活工作为两个主要入口，零基础就业作为补充入口，覆盖11类职业方向。诊断先梳理已有经验，再确认路线、目标和可用时间；结果页呈现已有经验、可迁移能力与待验证的任务。包含六步诊断、推荐依据、30天计划、时间预算调整、行动进度、11项模拟实操、结构检查、浏览器草稿与Markdown导出、国内官方资源搜索。

## 运行

无需安装依赖，执行 `node preview.mjs` 后访问 `http://127.0.0.1:8734`。也可把dist目录部署到支持静态文件的服务器。所有页面路由使用URL hash。

## 文件

- `dist/index.html`：页面容器、对话框和隐私说明。
- `dist/style.css`：响应式视觉设计；使用系统字体，不依赖外部字体服务。
- `dist/app.js`：职业任务库、诊断规则、计划生成、进度与导出。
- `.openai/hosting.json`：Sites托管配置。复用现有Site时保留其ID；其他托管平台不需要此文件。

## 能力边界

初版尚未接入大语言模型。方向建议采用任务库和明确条件规则；实操检查使用关键词和人工自查，不是语义评分或职业能力认证。可复制练习提示词到用户自己的AI工具。

未实现账号系统、跨设备同步、真实招聘数据抓取、招聘撮合、支付、自动政策更新或后台用户分析。当前托管访问默认私有，不能直接视作公开招募用户的网址。

用户勾选后才持久保存个人进度，数据保存在当前浏览器localStorage，键名taqi-v1，不上传服务器。未勾选时仅当前页面会话保留。可以导出或清除记录。

## 检查记录

已完成JS语法检查、三路径30项任务与时间预算检查、推荐方向限制检查。浏览器操作已检查六步诊断、财务方向结果、进度勾选、调整时间保留进度、刷新恢复、实操结构检查、资源搜索以及桌面和窄屏布局。没有真实宝妈试用或就业效果证据。
