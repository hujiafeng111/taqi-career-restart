# 她启 · AI 助力女性职业重新出发

更新日期：2026-10-13。

主要面向曾有职业经历、因生育或照护暂停工作的女性。两个主要入口是重返原职业、探索转型或灵活工作，保留零基础补充入口。覆盖 12 类职业方向，包括自媒体与内容运营；诊断可选副业探索目标。

## 当前功能

- 六步诊断、规则推荐、30 天行动路线、时间预算调整。
- 12 项 AI 岗位实操：任务材料、专属提示词、AI 初稿、最终交付版、核验与修改记录、作品导出。
- 明确规则的内容结构检查和人工自查。
- 服务端 智谱 作品反馈接口，需要配置 API 密钥后才可使用。
- 用户明确同意后，才提交当前模拟任务、交付版、修改说明。不会提交诊断经历、城市或照护顾虑。
- 可选的当前浏览器保存、Markdown 导出、官方就业资源导航。

## 运行与部署

本版已迁移至官方 Sites Vinext 服务端模板。前端源文件在 public/；首页由 app/route.ts 提供；模型接口位于 app/api/review/route.ts。构建生成的 dist/ 不应手工编辑。

安装依赖后执行 `npm run dev` 进行本机预览；执行 `npm run build` 构建。当前托管权限仍为原有私有权限。

## 智谱 配置

在托管环境配置 `ZHIPU_API_KEY`，必须标记为 secret；可选配置 `ZHIPU_MODEL`，默认 glm-5.3-flash。密钥不应写入源码、前端、README 或压缩包。

接口遵循 智谱 官方文档：https://docs.bigmodel.cn/

未配置时页面显示未连接，并保留提示词、自查、导出流程。POST 接口要求站点登录身份、同源请求与有效作品。应用在每个服务实例内限制并发和每小时请求次数；跨实例限流尚未实现，当前保留私有访问。

## 能力与验证边界

方向推荐仍为任务库与条件规则；不是模型能力评估、录用预测或就业承诺。AI 反馈需人工核实；练习不是职业认证。尚无真实用户或就业效果数据。
